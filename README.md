# 与你赴约

徐清宜的 9 月 9 日生日限定互动页。纯静态 HTML/CSS/JavaScript，可直接部署到 GitHub Pages。

## 本地预览

直接打开 `index.html`，或在项目目录运行任意静态服务器。

## GitHub Pages

将文件推送到 GitHub 仓库，在 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`、目录选择 `/ (root)`。
